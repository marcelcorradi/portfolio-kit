# Profile — Source of Truth for Content

Every claim in portfolio content must trace back to this file (or to something the owner confirms directly). Do not invent metrics, projects, roles, or dates. If a needed detail isn't here, ask the owner or leave a marked placeholder.

`/setup` fills in the identity and differentiator. The rest you build up with the owner as you write each case — add durable facts here as they're confirmed, so they aren't lost between sessions.

spine — get it from the owner before writing.)_
